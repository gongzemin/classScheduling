#### 1.0.6 2025/1/10

- **新增功能**：
  - 新增会员列表页，并支持按手机号、会员卡类型、截止日期范围进行查询。
  - 支持动态配置开课前多少小时和人数不够时自动取消课程，相关数据从数据库中动态获取。
- **性能优化**：
  - 将 ECharts 图表依赖包移至分包，提高页面加载性能。
